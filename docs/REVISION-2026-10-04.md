# Ficnexus — from-scratch revision (2026-10-04)

Read: README (lists ~15 major subsystems), docs/design/PROMPT-
frontier-llm-fanfiction-platform.md (389 lines — the origin
prompt), .specify/ (speckit manifests), crates/ (consensus,
forum-core, forum-import, scrapers), git (209 commits, active today).

The problem is visible before reading a single spec: there is no
single product spec — the design prompt is the closest thing, and
the README reads like a feature landfill.

1. **Tier the spec M1/M2/M3 before writing another word.** M1 =
   fichub.net replacement (scrape → generate EPUB/HTML/etc →
   serve library). Everything else (progression system, ability
   tree, recipe builder, extension marketplace, theme tokens,
   trust levels, roadmap consensus, forum, XP) is M2+ — and the
   README lists them all at equal weight. From scratch: the M1
   spec is ~300 lines; the rest is roadmap with dispositions. A
   spec that lists 15 subsystems is 15 specs, and none gets built
   well. (Gravity's intake discipline lesson: an intake that adds
   without deleting grows forever.)
2. **The origin prompt (docs/design/PROMPT-…) is a design input,
   not a spec — and it's filed where a spec would be.** From
   scratch: move it to docs/design/inputs/ with a one-line
   pointer from the README, and write the real spec against the
   decisions it produced. A prompt in the spec's chair makes the
   next agent build the prompt's fantasy, not the product.
3. **Scrapers are the legal and maintenance center of gravity.**
   The product dies when a source changes its markup; the spec
   should treat adapters as first-class citizens (gravity's §29
   import-spine pattern: adapters are descriptors, an unknown
   source fails by name, a bounded batch never truncates silently).
   Currently scrapers are a crate among equals — from scratch
   they're the most-spec'd component after the library model.
4. **.specify/ (speckit) + docs/plans/ + docs/sessions/ is three
   planning systems.** From scratch: ONE — plans/ for work, ADRs
   for decisions, sessions/ pruned to nothing (session notes are
   the thing that most often lies later; lorehaven's remaining-
   work.md header — "the previous header claimed 588… all of
   those are now wrong" — is the cost of believing them).
5. **Consensus + roadmap features came from gravity's playbook**
   (roadmap Elo/MaxDiff). If they ship here, they should be
   copied as the mechanism (engine + firewalls), not the feature
   list — and the firewalls (Elo never feeds content ranking,
   no reputation for participation) are the part worth copying,
   not the arena UI.

## Verdict
No product spec exists; the README is a feature landfill and the
   origin prompt is filed as a spec. Write the M1 spec (~300 lines),
   tier the rest as roadmap, promote scrapers to first-class
   spec citizens, collapse the three planning systems into one.
