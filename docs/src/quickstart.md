# Quickstart

Everything you need to go from zero to reading in about five minutes.

## 1. Download your first story (no account needed)

1. Copy a story URL from your favorite site. For example:
   ```
   https://archiveofourown.org/works/12345678
   ```
2. Open FicHub and click the **Download** tab.
3. Paste the URL into the box and click **Download**.
4. When the story info appears, pick a format:
   - **EPUB** — best for Kindle, Kobo, phones, tablets
   - **HTML** — read in any browser
   - **PDF** — printing or sharing
   - **TXT** — plain text, works everywhere

That's it — you're reading. No account, no email, no ads.

## 2. Create an account (unlocks the community)

Click **Register** in the top-right corner and pick a username + password.

With an account you can:
- **Bookmark** stories to read later
- **Rate** stories (helps recommendations)
- **Comment** and chat with other readers
- **Post in the forum** — start a topic or reply in any category
- **Get recommendations** based on what you read
- **Earn exp (experience)** and climb the leaderboard; leveling unlocks
  moderation powers

## 3. Save your first bookmark

1. Open a story page (click the title in search results).
2. Click the **♡ heart** button.
3. Add a note (optional) and hit **Save**.

## 4. Find something great

Click the **Search** tab and try a few things:

- `harry potter` — simple search (words combine with AND)
- `"slow burn"` — quoted phrase, matches the exact phrase
- `fluff OR humor` — either word
- `angst -fluff` — angst but NOT fluff
- `title:harry author:rowling` — field-specific

Then use the **filter chips** (Complete Only, 100k+ Words, No Warnings…) and the
**facet sidebar** (Fandoms, Characters, Relationships…) to narrow it down.
Full guide: [Finding Great Stories](./searching.md).

## 5. Read offline, everywhere

Every download is a self-contained file. Copy it to your phone, tablet,
e-reader, or laptop and read anywhere — no internet required.

## Cheat sheet

| I want to… | Do this |
|------------|---------|
| Download a story | **Download** tab → paste URL → pick format |
| Search stories | **Search** tab → type query → refine with chips/facets |
| Save a story | Open story page → click **♡** |
| Rate a story | Open story page → click 1 to 5 stars |
| Comment | Open story page → scroll to **Comments** |
| Find similar stories | **Recommendations** tab → paste a URL you liked |
| See my activity | Click your **username** → profile |
| See top readers | **Leaderboard** tab |
| Talk with the community | **Forum** tab → pick a category → post or reply |
