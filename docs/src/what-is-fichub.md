# What is FicHub?

FicHub is like a magic bookshelf for fanfiction. It takes stories from different websites and puts them all in one place.

## The Problem

Fanfiction is amazing, but it's scattered across many websites:
- **Archive of Our Own (AO3)** — the biggest fanfiction archive
- **FanFiction.net** — one of the oldest fanfiction sites
- **FictionPress** — for original fiction
- **SpaceBattles & SufficientVelocity** — forum-based stories

Each site has its own format, its own search, and its own rules. Finding a good story can feel like searching for treasure without a map!

## The Solution: FicHub

FicHub does three things:

1. **Brings stories together** — paste any link and FicHub downloads it
2. **Makes them easy to read** — converts to EPUB, HTML, or PDF so you can read on any device
3. **Helps you find more** — smart search, recommendations, and bookmarks
4. **Builds community** — a forum with categories, topics, follows, and
   moderation, plus comments, Fic Requests, and transparent moderation
5. **Levels you up** — earn XP, climb 100 levels, unlock features on the
   Ability Tree, customize your dashboard with widgets and themes
6. **Stays honest** — a public moderation log shows every staff action, and
   usage analytics are non-PII (anonymous client IDs only, never IPs)

## How does it work?

When you paste a story link, FicHub:
1. Goes to the website and grabs the story
2. Cleans up the formatting
3. Wraps it into a neat file you can download
4. Saves it so you can read it anytime — even offline!
