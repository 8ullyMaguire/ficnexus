# FicHub — Site Premise

FicHub is a self-hosted fanfiction archive and community platform written in Rust + SvelteKit, built as a full-featured alternative to AO3 and FanFiction.net for readers who want a site they control. It scrapes and caches fanfiction from 107 real sites (full FanFicFare adapter parity, no Python CLI dependency), exports to EPUB/HTML/MOBI/PDF/AZW3/TXT/MD, and serves a complete social surface on top: 5-star ratings, in-depth reviews, threaded comments, bookmarks, reading lists, follows + updates feed, series and author pages, RSS/Atom feeds, an in-browser reader with position save and "Next Up," plus a community forum with categories, topics, posts, moderation points, metamoderation, site-wide leveling, and topic slug URLs. The recommendation layer is a pluggable strategy platform (co-occurrence, time-decayed SAR, pgvector embeddings, implicit MF, tag/author/sequential graphs, bandit exploration) with a user recipe builder and entity recommendations (similar tags/fandoms/authors/collections/users). Trust and progression are separate axes: a 100-level/10-rank progression system with XP, ability tree, and rank-gated features, plus a Discourse-style 7-level trust axis (TL0–TL6) that sandboxes new accounts, gates gallery publishing at TL2, and lets TL5 Community Moderators resolve reports — all recorded in a public modlog. Ask-the-Archive turns natural-language queries into search filters via Ollama; Fic Requests is a prompt board where answers can be a work id, a pasted URL (URL-ingest), or an ask result; roadmap consensus runs a MaxDiff/Elo arena over pgvector-embedded feature clusters. Admin transparency covers auto-tag review, translation approval, metadata correction, anti-bot (honeypots, tiered rate limits, Redis shadowban, proof-of-work, hourly bot-scorer), usage analytics with zero PII, and a weekly moderation digest. The site is designed to be self-hosted on a single machine (PostgreSQL + Redis + Ollama), fronted by Cloudflare, and invited into small cohorts first — the one remaining content gap is outbound reachability from the host to AO3/FFN (Cloudflare block), tracked as a cookie-ingestion feature.
